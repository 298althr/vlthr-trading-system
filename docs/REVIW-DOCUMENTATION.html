Key Insight: 4 Factors Need Zero New Data

  • Funding rate sentiment: Already ingested every 8h. Compute funding_zscore = (current - rolling_mean) / rolling_std. High positive z = crowd long = contrarian SHORT signal for MR.
  • OI delta: Already ingested every 1h. Compute oi_delta_pct = (OI_now - OI_4h_ago) / OI_4h_ago. Rising OI + rising price = trend confirmation. Falling OI + rising price = weak rally.
  • Orderbook imbalance: Already ingested every 5 min. Compute bid_ask_imbalance = (bid_volume - ask_volume) / (bid_volume + ask_volume). > 0.3 = strong buy pressure.
  • Correlation regime: Compute from existing OHLCV. rolling_corr(BTC, ALT, 24h). High corr = macro driven. Low corr = symbol-specific.

These 4 factors can be extracted from existing parquet files with zero new API calls, zero new dependencies, and zero new infrastructure. They only need feature computation functions added to the enrichment pipeline.
