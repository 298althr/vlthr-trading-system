Overview

The AI Trader Engine is a FastAPI service that exposes the D1-D7 backtest pipeline, strategy management, data exploration, and an NVIDIA AI chat proxy. It reads OHLCV data from the shared Parquet store and connects to PostgreSQL for predictions and model state.

D1-D7 Pipeline Stages

The engine implements a 7-stage backtest pipeline. Each stage can be run independently or as part of the full pipeline. All stages operate on Parquet data loaded via pipeline/data.py.

D1: Data Quality Audit Stage 1

Validates input data integrity. Checks for gaps, outliers, stale bars, and schema compliance. Returns a quality report with pass/fail per check.

D4: Feature Discovery Stage 2

Computes technical indicators and assigns domain weights. Outputs a feature matrix with importance scores. Indicators include RSI, EMA, ATR, Bollinger Bands, MACD, and volume profile.

  • Module: pipeline/indicators.py — add_all() function
  • Output: Feature DataFrame with weighted columns
D5A: Mechanical Base Backtest Stage 3

Runs a mechanical backtest with fixed parameters. No optimization. Establishes baseline performance metrics: win rate, profit factor, Sharpe ratio, max drawdown, Sortino ratio.

D5B: Parameter Optimization Stage 4

Parameter sweep with in-sample / out-of-sample split. Tests parameter combinations on IS data, validates on OOS data. Reports overfitting risk and parameter stability.

D5C: DQS-Scored Backtest Stage 5

Backtest with Data Quality Score integration. Signals are scored on data quality (freshness, completeness, outliers). Only signals above the DQS threshold are taken. This is the stage that validates the DQS veto logic.

D6: Risk Sizing Stage 6

Position sizing with leverage and funding cost adjustments. Computes Kelly fraction, applies risk caps, and factors in funding costs for perpetual positions.

D7: Reality Probe Stage 7

Stress tests across multiple scenarios: latency injection, slippage modeling, fee variation, and adverse selection. Validates that the strategy survives real-world frictions.

Full Pipeline

The /pipeline/full endpoint runs all stages sequentially: D1 to D7. Returns combined results from all stages. Each stage's output feeds into the next.

Helper Functions

Shared helpers in pipeline/stages.py: _sharpe(), _max_drawdown(), _profit_factor(), _sortino(), _native() (numpy to Python type conversion).

NVIDIA AI Chat Proxy

The engine proxies chat completion requests to the NVIDIA integrate API. This allows the frontend and AI agents to use NVIDIA-hosted LLMs through a single endpoint.

NaN-Safe Serialization

The engine includes a _sanitize_nan() helper that recursively replaces NaN, Inf, and -Inf with null in JSON responses. This prevents invalid JSON from numpy calculations reaching the client.

API Key Required
The NVIDIA_API_KEY environment variable must be set in .env or ai-trader-engine/.env. Without it, the chat endpoint returns empty responses.

Docker Configuration

Service Definition
ai-trader-engine:
  build:
    context: ./ai-trader-engine
    dockerfile: Dockerfile
  container_name: ai_trader_engine
  ports:
    - "8002:8000"
  env_file:
    - .env
  environment:
    - DATA_ROOT=/app/data
    - DB_URL=postgresql://postgres:${POSTGRES_PASSWORD:-your_postgres_password}@vlthr-postgres:5432/postgres
  volumes:
    - ./data:/app/data
    - ./ai-trader-engine/.env:/app/.env:ro
  depends_on:
    postgres:
      condition: service_healthy
  networks:
    - vlthr-net
  restart: unless-stopped
  deploy:
    resources:
      limits:
        cpus: "2"
        memory: 1G
Dockerfile

Base image: python:3.11-slim. Installs gcc and g++ for numpy/pyarrow wheel builds. Python packages from requirements.txt. Runs uvicorn main:app on port 8000 with --log-level info.

Health Check
Docker healthcheck runs python -c "import urllib.request; urllib.request.urlopen('http://localhost:8000/health')" every 30 seconds. Start period: 15 seconds. Retries: 5.
CORS Configuration

CORS is configured via FastAPI middleware. Allowed origins:

  • http://localhost:5174 (frontend dev)
  • http://localhost:3002 (backend dev)
  • NGROK_DOMAIN from env (production HTTPS tunnel)
