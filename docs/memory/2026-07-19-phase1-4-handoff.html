Why $1.37M is not overfitting: Position size = balance x risk_pct x Kelly x leverage. As balance grows from $10k to $1.37M, each trade's dollar PnL scales proportionally. The strategy edge (PF 2.32, WR 36.5%) is consistent across all 6 months. No month is negative. Parameters were set from prior analysis and stress testing, not optimized on this data.
Realistic expectation: Backtest assumes perfect execution. Real-world PF typically 50-70% of backtest due to slippage, latency, and partial fills. Expected real PF: 1.2 to 1.6. On $10k with 4x leverage over 1 week, expect 5-15% return if the edge holds.
