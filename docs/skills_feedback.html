Known Issues & Bugs

Documented in Skills

  • Symbol disable deadlock: Evaluates all historical trades instead of last 15. Causes all symbols to be disabled.
  • Daily loss breaker too tight: -2% breaker on 33% WR strategy trips too early. Consider -3%.
  • No SHORT signals: V2 daily bias filter too restrictive. Under investigation.
  • Dynamic SL decay divergence: Paper SL decays (0.15 rate), Bybit SL is fixed at creation. Structural, not a bug.
  • Reconciliation delay: Bybit close detection on next 5-min cycle. Paper closes instantly. Up to 5 min divergence.
  • Time exit not on Bybit: Paper time exit is automatic. Bybit requires manual close order.
  • RCA calibration: 2/3 cross-domain validation misses (power, telecom keyword gaps). Keyword proxy does not match real incident terminology.
